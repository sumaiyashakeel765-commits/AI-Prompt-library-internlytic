Project Overview

This project is a collection of 45 reviewed and reusable AI prompts designed to help internship teams work more consistently and efficiently.

Project Categories

The library covers six areas:

- Recruitment & Applicant Support
- Internship Operations & Onboarding
- Task Instructions & Submission Guidance
- Marketing & Social Media Content
- Project Planning & Technical Support
- Quality Assurance, Editing & Fact-Checking

Key Features

- 45 reusable prompts with customizable placeholders
- Clear instructions and expected output formats
- Review checklists for evaluating AI-generated responses
- Five improved prompts based on previous testing
- Responsible AI-use guidelines emphasizing privacy, fact-checking, and human review

Skills Demonstrated

- Prompt Engineering
- AI Output Evaluation
- Technical Documentation
- Quality Assurance
- Responsible AI Use

How to Use

1. Select a prompt relevant to your task.
2. Replace the placeholders with appropriate information.
3. Run the prompt in an AI assistant.
4. Verify the output and review it before use.
